# 验证方法

虚构商事案卷提供基础、复杂、缺损三批次与合成录音。评估代理只接收 Skill 和原始案卷，不读取作者整理结果及答案；在独立目录实际执行。

内容检查：出处可回查；事件和重名主体不错误合并；模糊原话不定性；冲突和缺失材料显露。按具体金额、日期、引用核对，不以文字完整代替正确。

增量检查：重复文件、同路径改版、新材料、新版本、人工更正金额为 0、已复核事实变化和 Excel 回导。保留旧号，冲突列为待确认变更。

录音检查清晰合成语音和静音；回听定位正确、时间戳不越界、静音不生成事实。模拟测试不等于真实录音准确率。

视觉检查 Excel 七表和网页桌面、375px 手机、打印：原话及出处无裁切，搜索、筛选、展开和回听可用。

## v0.2 实际工作验收

接案到补证使用同一案件编号与版本链。对用户指定的熟悉案件，先对平材料清单，再与律师独立准备的关键事实、冲突和缺失附件清单核对；模型不读答案。所有关键金额、日期、主体与原话回原件留记录，实际新增一次补材料，核查关闭至少一项问题。

记录首次整理、律师复核、修正与补证总用时，报告漏项、错误和修复。材料漏登记、错案回导、杜撰原话、人工记录丢失、静默显示完成均须修复后重验。完成单宗试用不推导通用准确率。真实案件路径未指定时，该项列为未执行，继续交付其他已完成改进。


## v0.3 本轮回归

用60份原模拟材料的同一118条事实生成新底稿，只新增虚构演示人工选择。对比所有原始事实字段、179条引用、金额摘要和稳定编号不变。检查旧表和新表回导、是/否/空白区别、明确清除分组、类型拒绝的原子性、三轮补材料及金额0保留。人工分组或false重点同样保护记录。

网页隔离逻辑测试检查总表/重点/分组计数、时间顺序与未知日期、常用/高级筛选、关联跳转、可见详情保留、录音元数据后定位、打印范围及500条事实检索。该测试不运行真实浏览器，不能证明桌面/375px/A4布局或实际回听通过。Excel单元格预览与布局检查单独记录。真实案件试用另行记录，不以演示替代。
