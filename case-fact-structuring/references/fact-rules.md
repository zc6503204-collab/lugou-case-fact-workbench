# 事实整理规则

“那50万后面统一处理”记录为沟通出现该表述；债务确认、付款承诺等解释交给后续判断。合同约定履行日与聊天描述交付日不一致时分别记录，不直接认定谁记错。

转账记录能整理付款方、收款方、金额、时间和备注；价款、借款等性质有分歧时并列。不能把合同总价、欠款主张和转账发生额合计。

文件落款日、事件发生日、邮件发送日和录音时间分别处理。相对日期只有上下文明确才计算并保留依据。日期只到月或范围时不补具体日。

工商名称、签约主体、账户名、聊天昵称和说话人分开保留。“张伟”重名、代表公司、代付款等身份关系需材料支持。金额相同或日期接近不足以合并事件；核对交易对象、编号和上下文，不能确定写“可能相关，待核”。

PDF 实际页从 1 开始；纸面页码只在实际看到时填写。Word 保留段落号或表格行列号，Excel 保留工作表/单元格及公式缓存差异。图像保留 OCR 块位置；录音保留原文件、起止秒数和是否听核。

OCR 和自动转写供导航；识别疑点显露，没有原件支持的补字不悄悄写入关键原话。人工更正另存，与原始提取并列。

冲突与缺口写清：材料分别说什么、关联哪些事实、缺什么、建议回核哪处或补什么。缺附件不等于附件不存在；未发现催告记录不等于从未催告。

打不开、加密、识别失败和新版本覆盖均留材料记录，只暂停受影响的路径。材料中的评价和策略标明来源，不转换为本 Skill 的独立结论。
